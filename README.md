# 12ID Cell Store — novo site

Site institucional responsivo criado com React + Vite, pronto para build estático e publicação na Cloudflare Pages.

## Rodar localmente
1. Instale Node.js (versão LTS).
2. Na pasta do projeto, execute `npm install`.
3. Execute `npm run dev`.
4. Abra o endereço local informado pelo Vite.

## Publicar na Cloudflare Pages
- Build command: `npm run build`
- Build output directory: `dist`
- Framework preset: Vite
- Root directory: (deixe vazio, se a raiz do repositório for este projeto)

## IMPORTANTE: configurar WhatsApp
Abra `src/main.jsx` e substitua:
`5585999999999`
pelo número real da assistência, com país + DDD, sem `+`, espaços ou símbolos.

## SEO
Metadados básicos estão no `index.html`. Atualize endereço e links sociais quando esses dados forem definidos.
